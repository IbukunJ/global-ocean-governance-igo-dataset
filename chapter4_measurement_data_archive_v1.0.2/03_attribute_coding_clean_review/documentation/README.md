# Attribute coding and CLEAN review — public-safe edition

The complete coding stage reviewed 3,636 candidate records and produced 3,676 decision-log entries and 3,074 accepted or retagged traceability records. Automated retrieval surfaced candidates; researcher-led CLEAN review made the final coding decisions.

This public edition replaces evidence-rich source tables with metadata-only audit indexes:

- `data/ch04_s3_candidate_review_index_public_3636.csv`
- `data/ch04_s3_decision_log_public_3676.csv`
- `data/ch04_s3_traceability_index_public_3074.csv`

The indexes preserve record IDs, organisation and attribute assignments, evidence tiers, source locators and URLs where recorded, trigger terms, actions, decision rationales, review notes, and SHA-256 hashes of withheld text. They do not reproduce candidate excerpts, source-title strings that functioned as evidence, or duplicated long-form matrix narratives.

The original consolidated Step 3 workbook is not distributed because it embedded the excluded fields. Summary tables, coverage diagnostics, configuration, code, and environment records remain available.
