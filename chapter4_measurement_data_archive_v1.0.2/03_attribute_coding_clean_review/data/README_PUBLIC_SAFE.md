# Public-safe coding audit tables

The complete research archive contained candidate excerpts, long-form evidence, and duplicated matrix narratives. This public-safe edition replaces those evidence-rich tables with metadata-only indexes:

- `ch04_s3_candidate_review_index_public_3636.csv`
- `ch04_s3_decision_log_public_3676.csv`
- `ch04_s3_traceability_index_public_3074.csv`

The public indexes retain record identifiers, coding decisions, evidence tiers, source locators and URLs where recorded, trigger terms, researcher rationales, review notes, and SHA-256 hashes of withheld text fields. The hashes allow authorised holders of the restricted archive to verify correspondence without exposing the text itself.

The original Step 3 consolidated workbook is not included because it embedded the excluded fields.
