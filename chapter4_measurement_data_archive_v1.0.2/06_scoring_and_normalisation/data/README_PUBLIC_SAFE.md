# Public-safe scoring inputs

The source-dependent RAW and CLEAN narrative workbooks are excluded from this public edition because they contain long-form institutional descriptions. The Year of Establishment files are retained because they contain researcher-generated temporal variables rather than source-document text.

The public archive retains:

- the reconciled category schema;
- the 48 × 80 category activation matrix;
- corrected matrix-wide family outputs;
- the hybrid-score matrix;
- within-IGO and across-IGO normalised matrices;
- descriptive statistics;
- the corrected master matrix; and
- the R code documenting the scoring and normalisation logic.

The code is retained for methodological transparency, but an end-to-end rerun from institutional source text requires the restricted inputs or locally reacquired documents. The supplied public matrices are the canonical analytical outputs.
