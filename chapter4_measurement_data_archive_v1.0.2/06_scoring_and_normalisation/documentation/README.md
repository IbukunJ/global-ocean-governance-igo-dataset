# Hybrid scoring and dual normalisation — public-safe edition

This stage retains the corrected R pipeline, reconciled category schema, matrix-wide family outputs, equation-consistent hybrid and normalised matrices, descriptive statistics, and final analysis-ready products.

Text-bearing RAW/CLEAN narrative workbooks, KWIC traceability CSVs, and family workbooks embedding verbatim evidence are excluded from the public edition. Their corresponding matrix-wide outputs are retained under `outputs/family_csvs/`. The Year of Establishment inputs remain because they contain researcher-generated temporal metadata rather than institutional source text.

The Stage B code was amended so that bounded RAW frequency contributes only where CLEAN presence is confirmed. Verified hybrid scores comply with Equation 4.1, and the canonical within-IGO and across-IGO values were regenerated under Equations 4.2 and 4.3.

The code is included for methodological transparency. An end-to-end text-to-score rerun requires the restricted inputs or locally reconstructed source corpus. For public secondary analysis, use the supplied category activation, hybrid, normalised, descriptive, and master matrices.
