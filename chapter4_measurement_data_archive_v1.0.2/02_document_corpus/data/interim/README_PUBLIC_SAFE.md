# Public-safe corpus indexes

The public archive excludes extracted page and paragraph text. It supplies metadata-only indexes instead:

- `ch04_s2_page_index_public_2435.csv.gz`
- `ch04_s2_paragraph_index_public_5159.csv.gz`

These files retain stable identifiers, structural locators, character counts, and SHA-256 hashes. They permit count verification and local identity checks without redistributing the institutional source text. `ch04_s2_extraction_log_130.csv` is retained because it records extraction status and exceptions rather than source content.
