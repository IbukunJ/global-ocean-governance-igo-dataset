# Attribute Matrix integration and validation — public-safe edition

This stage contains the 48-case baseline Attribute Matrix, the 480-row long-form matrix, coverage and integrity diagnostics, and the zero-row orphan-evidence register. The wide matrix includes nine substantive governance attributes plus the auxiliary `Scale` field.

The baseline matrix is a researcher-generated institutional synthesis and is retained as the principal qualitative measurement product. Step 4 adds no new source evidence; it standardises identifiers, consolidates retained decisions, and preserves record identifiers linking matrix cells to the public Step 3 traceability index.

The release copy of `step4_integrate.py` documents the integration procedure and corrects the orphan-register assignment bug present in the source version. A complete rerun requires the evidence-rich Step 3 input workbook, which is withheld from the public edition. The integrated matrix and validation outputs supplied here are canonical.
