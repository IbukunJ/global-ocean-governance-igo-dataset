# Documentation and provenance files

This folder retains the original codebook, master-matrix dictionary, and methodological-pipeline document for provenance. Files labelled `source_original` are not treated as the authoritative release schema where they differ from the corrected machine-readable files. The authoritative 80-category schema is `05_category_schema/data/ch04_s5_category_schema_80_reconciled.csv`, and the authoritative scoring rules are the equations in Chapter 4 together with the corrected code and outputs in Stage 6.

The original methodological-pipeline document is retained because it records the development history of the workflow. Some terminology and parameter descriptions pre-date the final chapter and should therefore be read alongside `VALIDATION_STATUS.md` and the stage-level README files.
