# Category schema

The canonical Chapter 4 analysis schema contains 80 categories across eight substantive attribute families. `../data/ch04_s5_category_schema_80_reconciled.csv` reflects the category labels and tier values used in the verified scored outputs. The corresponding 48 × 80 CLEAN-confirmed category states are recorded in `../data/ch04_s5_category_activation_matrix_48x80.csv`. The original source schema remains in `../config/` because several labels differed from those used in the final scored outputs.

`ch03_attribute_category_identification_v1.0.docx` is included as a read-only methodological provenance source. It originated in the Chapter 3 attribute-development process and documents the development, consolidation, and mapping of candidate categories to the substantive governance attributes. It is researcher-generated, not a Chapter 4 executable data product.

For public reproducibility, the reconciled CSV schema is the authoritative machine-readable specification, the activation matrix is the authoritative organisation-level coding output, and the corrected matrix-wide files in Stage 6 are the authoritative family-level score products. Evidence-bearing family workbooks from the restricted archive are not publicly distributed.
