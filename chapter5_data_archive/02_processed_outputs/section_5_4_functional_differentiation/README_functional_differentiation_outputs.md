# Functional differentiation outputs

This folder contains the full 48-IGO functional differentiation outputs used for revised Chapter 5.

## Full 48-IGO exports

- `regulatory_delivery_scores_all_48_igos.csv`: full score export for Figure 5.10, including the component categories used to calculate regulatory strength and delivery capacity.
- `figure_5_10_regulatory_delivery_plot_data_all_48_igos.csv`: concise plot-ready data for Figure 5.10.
- `functional_alignment_scores_all_48_igos.csv`: full ranked functional-alignment scores for Figures 5.11 and 5.12.
- `functional_orientation_classes_all_48_igos.csv`: full 48-case class membership table.
- `functional_orientation_class_counts_all_48_igos.csv`: class counts and members for Table 5.11 and Figure 5.12.
- `figure_5_11_functional_alignment_plot_data_all_48_igos.csv`: plot-ready ranked data for Figure 5.11.
- `figure_5_12_functional_orientation_sunburst_data_all_48_igos.csv`: hierarchy-ready data for Figure 5.12.
- `functional_score_construction_audit.md`: formula and provenance notes for the Section 5.4 outputs.

## Selected tables retained

The folder also retains the selected tables already used in the Chapter 5 prose:

- `table_5_10_selected_regulatory_delivery_gap_results.csv`
- `table_5_11_functional_orientation_classes.csv`
- `table_5_12_selected_functional_alignment_scores.csv`

The full exports should be treated as the primary data files for final deposit.

Corrected duplicate figure-ready data files are included as `figure_5_11_functional_orientation_sunburst_data_all_48_igos.csv` and `figure_5_12_functional_alignment_plot_data_all_48_igos.csv`.
