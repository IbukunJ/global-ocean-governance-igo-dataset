# Normalised attribute workbooks — public-safe edition

The complete restricted workbooks contained two sheets:

- `Traceability_Long`, with verbatim institutional descriptions, cleaned text, keyword frequencies, trigger mappings, KWIC snippets, and scoring provenance; and
- `Matrix_Wide`, with the 48-organisation analytical score matrix used by the Chapter 5 workflows.

For public distribution, the eight substantive attribute workbooks retain **only `Matrix_Wide`** under their original filenames. The `Traceability_Long` sheets are withheld because they reproduce source-derived text and evidence snippets originating in the restricted measurement pipeline. The 48 data rows and 22 columns of every retained `Matrix_Wide` sheet were compared cell-by-cell with the complete archive and are unchanged.

`year_of_establishment_categories_density.xlsx` did not contain an evidence-rich traceability sheet and is retained unchanged.

This boundary preserves the analytical inputs needed for secondary analysis while avoiding redistribution of evidence-rich source text. See `../../05_quality_assurance/workbook_sanitisation_report.csv`.
